# KiCadD tools: the full descriptions

Generated by `kicadd-mcp --tool-docs` (do not edit: the text lives with each tool in mcp/*.cpp). The MCP tools/list sends only the first line of each; `tool_help {name}` returns the rest.

## board_summary

Counts, copper layers, outline, via kinds and aspect ratio of the open PCB (mm, Y down), and the full unrouted count. Start here.

Counts, layer count and board outline of the open PCB. Units: mm. KiCad's Y axis points down. The vias by kind (type, pad / drill) and, with the board thickness, the worst through-via aspect ratio (thickness / drill; your fab's limit judges it). Then the complete unrouted-connection count: the ratsnest of large nets deferred during moves is rebuilt first (not while the editor is busy or auto_place runs: said so).

## query_area

Items near a part or a point, nearest first (pads with their size). Use instead of dumping the board; via_net finds free via spots.

Items near a footprint (ref: the part itself first, then what is around it) or a point (x,y), nearest first. Lines: KIND handle [net] layer @x,y (pads are REF.PADNUM WxH, the copper as placed; tracks start>end wWIDTH; ~DIST from the centre). via_net=NET lists free via spots instead (off pads; in a QFN's pad ring too, marked *). Use this instead of dumping the board.

Parameter notes:

- kinds: Item kinds to include (default: footprint, pad, track, arc, via)
- via_net: Instead of items: free spots for a through via of this net (its class's size) within the radius, nearest first

Arguments:

- `kinds` (array): Item kinds to include (default: footprint, pad, track, arc, via)
- `limit` (integer, >= 0): Max items (default 64; via spots 8)
- `radius` (number, mm, > 0, required): Radius, mm
- `ref` (string): Centre on this footprint
- `via_net` (string): Instead of items: free spots for a through via of this net (its class's size) within the radius, nearest first
- `x` (number, mm): Centre X, mm
- `y` (number, mm): Centre Y, mm

## move_footprints

Move parts by a delta or to absolute places (x, y, rotation, side), one undoable edit; returns a local DRC around them.

Move/rotate/flip footprints as one undoable edit: refs with dx / dy / rotate / flip (move, then rotate, then flip; each around its own anchor, or as a group with pivot=group), or parts {"U1": {"x": 105, "y": 120, "rotation": 90, "side": "bottom"}} to put each where it is to be (absolute: anchor mm, orientation as KiCad shows it, side top / bottom; what is left out stays). Returns new positions (B.Cu = bottom side), the unrouted-connection count and a local DRC of the moved parts (clearance, shorts, hole clearance, courtyard overlap, board-edge clearance, copper outside the board). Large nets (GND, power) skip ratsnest updates while you iterate; the count says which.

Parameter notes:

- flip: Move to the other side (F.Cu <-> B.Cu), mirrored left-right
- pivot: Rotate/flip each part around its own anchor (default) or the parts as one group around their common centre

Arguments:

- `detail` (boolean): List every part / violation (default: long lists cut short)
- `dx` (number, mm): Delta X, mm
- `dy` (number, mm): Delta Y, mm (down is +)
- `flip` (boolean): Move to the other side (F.Cu <-> B.Cu), mirrored left-right
- `parts` (map): {ref: {x, y, rotation, side}}, absolute
- `pivot` (one of each, group): Rotate/flip each part around its own anchor (default) or the parts as one group around their common centre
- `refs` (strings): Reference designators, e.g. ["U5", "C12"]
- `rotate` (number, °): Rotation delta, degrees CCW

## lcsc_fetch

Get an LCSC part's footprint, symbol and 3D model into the project libraries, with stock and price.

Get the footprint and schematic symbol of an LCSC part (e.g. C8734) from the JLCEDA/EasyEDA Official Library: converted to KiCad, saved to the project library LCSC (lcsc.pretty + lcsc.kicad_sym, added to fp-lib-table and sym-lib-table; the symbol's Footprint field points at the footprint), cached for offline use. Returns both lib_ids, size, pad numbers/positions and any pin/pad mismatch. Its 3D model (EasyEDA's, converted to VRML in lcsc.3dshapes/, placed as EasyEDA places it) comes along for the 3D viewer unless model=false. add_footprint with lcsc does this by itself. Pin types: unspecified ones from their names, supplies the data typed bidirectional too (said); pin_types {pin number or name: type} sets others (input, output, bidirectional, tri_state, passive, power_in, power_out, open_collector, no_connect ...) in the library symbol. Copper pads with no number (a USB-C shell) take the symbol's one pin with no pad (EH), or unnumbered_pads=<pin>; said.

Arguments:

- `lcsc` (string, required): LCSC part number, e.g. C8734
- `model` (boolean): the 3D model too (default true)
- `pin_types` (map): set pin types: {"VREG_VOUT": "power_out", "12": "input"}
- `refresh` (boolean): Fetch again; replaces an edited footprint / 3D model
- `unnumbered_pads` (string): number shell pads with no number as this pin

## add_footprint

Place a new footprint as one undoable edit: from a library (footprint = "Library:Name", e.g. "Capacitor_SMD:C_0603_1608Metric"), from an LCSC part number (lcsc = "C8734", fetched and saved to the project library), or as a copy of a part already on the board (like = "C12"). ref "C?" takes the next free number. nets maps pad numbers to nets; unknown nets are created and reported. Returns the placement, unrouted count and local DRC.

Arguments:

- `detail` (boolean): List every part / violation (default: long lists cut short)
- `footprint` (string): Library:Name
- `lcsc` (string): LCSC part number, e.g. C8734 (instead of footprint)
- `like` (string): Copy the footprint of this ref instead
- `nets` (map): Pad number -> net name, e.g. {"1": "+3V3", "2": "GND"}
- `ref` (string): Reference, e.g. C301 or C? (default: prefix of like)
- `rotate` (number, °): Orientation, degrees CCW
- `value` (string): Value, e.g. 100nF
- `x` (number, mm, required): Position X, mm
- `y` (number, mm, required): Position Y, mm

## delete_tracks

Delete tracks / vias (all, by net, by part, or in an area), as one undoable edit.

Delete routing (tracks, arcs, vias) as one undoable edit, e.g. before auto_place on a routed board. all: every track; nets: by net name; refs: the copper running from these parts' pads up to the next pad (rip up their connections); region: [x0, y0, x1, y1] mm, anything crossing it. Given together, nets / refs / region narrow each other (GND in this box). The answer lists what went per net. Locked tracks stay unless include_locked. Zones are not touched (refill_zones afterwards). Returns the new unrouted count.

Arguments:

## route

Draw one connection like the interactive router (to a pad, a point, or the net's pour). Not an autorouter.

Draw one connection the way the interactive router does (45-degree tracks around obstacles; existing copper is never moved; the net class's width and via, the clearance, keepout and edge rules). Not an autorouter: say what to connect. from: a pad "U1.5" or a point [x, y] on the net's pad / track / via (inside a pad: the track leaves the pad there, for a way out between close pads); to: likewise, or any point (a free end), or "zone": the net's own pour, its nearest filled copper (on the start's layer, else with a via down to the nearest layer that has it: a pad to a VBUS / GND pour); without to: the nearest unrouted connection of from. waypoints: [[x, y], ...] to pass through, [x, y, "B.Cu"] puts a via there and goes on on that layer; via: [x, y] is short for one via to the other side (the end's layer); to "zone" with the last via over the net's pour (on its layer; via: any layer): the route ends in that one via (on the start point: only the via). layer: where to start (default: the start pad's / the end's / F.Cu); width in mm. Reports length vs the straight line, segments, vias and the narrowest gap; when blocked, how far it got and what is in the way, and how far it leaves the box between two waypoints (strict=true refuses that). One undoable edit; dry_run reports without drawing. Mm, Y down.

Parameter notes:

- from: "U1.5" or [x, y] (a point inside a pad: the track leaves the pad there, not at its centre)

Arguments:

- `dry_run` (boolean)
- `from` (any, required): "U1.5" or [x, y] (a point inside a pad: the track leaves the pad there, not at its centre)
- `layer` (string)
- `strict` (boolean): refuse a route that strays off the waypoints
- `to` (any): "C3.1", [x, y], or "zone" (the net's pour); omit: ratsnest
- `via` (array)
- `waypoints` (array)
- `width` (number, mm, > 0)

## route_short

Route the shortest unrouted connections of given parts / nets, one by one as route does, with vias where one layer won't do.

Route the unrouted connections (ratsnest lines) of refs and / or nets, shortest first (the short ones have the fewest ways round, so they go first and block the least), each as route does; max_length (mm) leaves the long ones to the user. Through-hole to through-hole: F.Cu, then B.Cu if blocked, unless layer is given; when the nearest copper of the other end can't be reached (a track on the far layer), the pads and vias joined to it, nearest first. A connection that can't be done on one layer gets vias (vias=false: none): ends on different layers one via on the way, on the same layer over the other side and back, the spots along the straight line tried in turn, none inside the pads of an IC with an exposed / thermal pad (a QFN: allow_under_ic=true allows it; an LQFP's body is free). The failures say how far they got and what is in the way (delete_tracks or move the part). Nets with a copper zone that come in through refs are skipped and listed (the pour joins them; include_poured=true, or name the net in nets, to route them); skip_nets (globs) leaves others alone, e.g. a net to be poured later. All of it is one undoable edit; dry_run reports what would and would not route without drawing.

Arguments:

- `allow_under_ic` (boolean): vias under a QFN's body too (default false)
- `detail` (boolean): List every part / violation (default: long lists cut short)
- `dry_run` (boolean)
- `include_poured` (boolean): also nets with a zone (default: skipped)
- `layer` (string)
- `max_length` (number, mm, > 0)
- `nets` (strings): Net names, e.g. ["GND", "/USB_D+"]
- `refs` (strings): Reference designators, e.g. ["U5", "C12"]
- `skip_nets` (strings): net globs left alone, e.g. ["GND"]
- `vias` (boolean): default true

## fanout

Short track + via from SMD pads to a pour of the same net on another layer (GND / power fan-out).

Fan out SMD pads of nets (e.g. GND, +3V3) to a copper zone of the same net on another layer (an inner plane, or the other side of a 2-layer board): a short track and a via next to each pad, inside that zone, as route would draw them. Through-hole pads are skipped (they reach every layer), and so are pads already joined to the zone; a net without such a zone gets a warning, not dangling vias. refs: only these parts; layer: the zone's layer. One undoable edit; the zones are refilled afterwards (refill=false to skip); dry_run reports without drawing.

Arguments:

- `detail` (boolean): List every part / violation (default: long lists cut short)
- `dry_run` (boolean)
- `layer` (string)
- `nets` (strings, required): Net names, e.g. ["GND", "/USB_D+"]
- `refill` (boolean)
- `refs` (strings): Reference designators, e.g. ["U5", "C12"]

## stitch_vias

Stitching vias on a grid over a net's pours (default GND), plus one per unconnected island.

Stitching vias for a net's pours (default GND): through vias on a grid (spacing, default 5 mm; area [x0, y0, x1, y1] mm, default the whole pour), each inside the net's filled copper on two or more layers (a net poured on one layer only, an inner plane: inside it, area required), clear of pads, tracks, holes, the edge and rule areas, and outside the parts' courtyards (under_parts=true allows them there). Then one via in each island of the net's copper that has none (islands=false skips it). Net class via size. The zones are refilled before and after; one undoable edit; dry_run counts without adding. at: [x, y] or [[x, y], ...] mm (net required) puts one via at each instead (no pour or grid needed; a via route can't place on its own), checked as route's vias are, each said with what of the net it lands on (zone, track, pad, or nothing yet).

Arguments:

- `area` (array)
- `at` (array): [x, y] mm or [[x, y], ...]: vias just there
- `dry_run` (boolean)
- `islands` (boolean)
- `max` (integer, >= 0)
- `net` (string)
- `refill` (boolean)
- `spacing` (number, mm, > 0): mm
- `under_parts` (boolean)

## set_rules

No arguments: the net classes, patterns and minimums. Else change classes (width, clearance, via, diff pair, current, impedance), assignments or fab presets, undoable.

With no arguments: the design rules (net classes with clearance, track width, via, diff pair and how many nets each has, unset values from Default; the net class assignments by name pattern; the board's minimum constraints; mm). With arguments: Change the design rules as one undoable edit (undo / redo; save_board writes them to the project file). classes: {"Power": {"track_width": 0.5, "clearance": 0.25}} adds or changes a class (only the values given; null: take it from Default); {"Power": {"current": 2}} sets the track width a 2 A net needs (IPC-2221, the board's outer copper, temp_rise 10 C unless given); {"RF": {"impedance": 50}} sets the track width for 50 ohm and {"USB": {"diff_impedance": 90}} the diff pair width and gap for 90 ohm, from the board's stackup on impedance_layer (default F.Cu; board_setup stackup=... first for a fab's numbers): the pair's width at diff_pair_gap if given, its gap at diff_pair_width if given, else its width with the class's clearance as the gap; the note gives the widths on the other layers and warns of reference layers not poured yet; remove_classes: [...]; assign: {"+5V": "Power", "/USB_D*": "USB", "GND": null} sets or drops net name patterns; constraints: {"min_clearance", "min_track_width", "min_via_diameter", "min_through_drill", "min_annular_width", "hole_clearance", "hole_to_hole", "copper_edge_clearance", "min_silk_text_height", "min_silk_text_thickness"} (mm). preset: a fab's standard process as the board minimums (and the Default class raised to them): jlcpcb_2layer, jlcpcb_4layer, jlcpcb_6layer; the rest of the call goes on top. Existing tracks keep their width. drc (default true) runs DRC before and after and reports the change in errors. The answer ends with the rules as they are now.

Arguments:

- `assign` (map)
- `classes` (map)
- `constraints` (map)
- `drc` (boolean)
- `preset` (one of jlcpcb_2layer, jlcpcb_4layer, jlcpcb_6layer)
- `remove_classes` (strings): Net class names to remove, e.g. ["USB"]

## zones

List, create or change copper pours.

Copper zones (pours): list, create, or change them. No arguments: the list (id, net, layers, priority, clearance, minimum width, pad connection). create: a new zone, e.g. {"create": {"net": "GND"}} pours GND on F.Cu and B.Cu over the whole board; {"create": {"net": "GND", "layers": ["In1.Cu"]}} makes an inner plane; rect [x0, y0, x1, y1] or outline [[x, y], ...] (mm) for a part of the board. Where zones of different nets overlap, the higher priority is filled and the other keeps clear: a new zone inside a bigger one is put above it, and an overlap at the same priority is warned about. Change settings: choose with nets, layers, ids (from the list) or all=true, and give clearance, min_width (mm), priority, connection (solid / thermal / none / thermal_tht), thermal_gap, thermal_spoke (mm). Each is one undoable edit, refilled afterwards unless refill=false.

Parameter notes:

  - `create.net` (string): e.g. GND

  - `create.rect` (array): [x0, y0, x1, y1] in mm: a rectangle

## impedance

Track width for a Z0 / pair for a Zdiff (or the impedance of a width) per layer, from the stackup.

Controlled impedance from the board's stackup, per copper layer; changes nothing (set_rules impedance / diff_impedance writes it into a net class). A layer's reference planes are the nearest plane layers each way: zones over 40% of the board (an unpoured layer: typed power, or empty), not by name; signal layers between are passed over (their copper in H, said). An outer layer is a microstrip over its plane (with the solder mask), an inner one a stripline between two, or an embedded microstrip with a plane on one side; the note lists each layer's coverage. The planes must be poured (zones create) for it to hold. z: a track's width for this Z0 (ohm); z_diff: a pair's width at gap (mm, default 0.2), or its gap at width; neither: the impedance of width (and gap: of the pair). ground_gap (mm): ground copper beside a single track on an outer layer (coplanar waveguide with ground, CPWG: a 2-layer board's way to a lower Z0 at a usable width; pairs with a pour beside them are not worked out). layers: default all. Uses KiCad's transmission line calculations (as pcb_calculator); set board_setup stackup=... first for a fab's dielectrics, and check with the fab's calculator before ordering.

Parameter notes:

- layers: copper layers, e.g. ["F.Cu", "In2.Cu"]; default all

Arguments:

- `gap` (number, mm, > 0)
- `ground_gap` (number, mm, > 0): mm to ground copper beside it (CPWG)
- `layers` (strings): copper layers, e.g. ["F.Cu", "In2.Cu"]; default all
- `width` (number, mm, > 0)
- `z` (number, Ω, > 0)
- `z_diff` (number, Ω, > 0)

## undo

Undo (redo=true: redo) the agent's last board edit, or with target="schematic" its last schematic edit.

## lcsc_search

## auto_place

Place parts inside the outline near what they connect to, with optional rules (edges, regions, groups), undoable.

Place parts automatically inside the board outline: each part goes near what it connects to (decoupling caps and pull-ups next to their IC pin), courtyards kept apart, rotations tried, as one undoable edit. Default: the parts outside the board (new from sync_pcb); refs for chosen parts, all for every unlocked part; fixed keeps parts where they are (place connectors first, then lock or fix them). Mounting holes (board_outline's H1..., MountingHole footprints) stay unless refs names them. Functional blocks are kept together: from groups, else the parts' Block field (sch_add_part block); groups "sheets" uses the schematic sheets, false none. Keeping blocks together costs some wire length (group_weight trades one for the other). Bottom side: back lists parts that may go there, back_decaps lets decoupling caps (C*) go under their IC pin (SMD only; off by default: two-sided assembly costs more); with either given, other SMD parts already on the bottom come to the top (without, parts keep their side). When every part is already placed (no overlaps, no rules), a result that is not better than the current placement is not applied (force applies it anyway). - `discard` (boolean)

## batch

Run several tools in one call (repeated or routine work).

Run several tools in one call, in order: steps [{"tool": "move_footprints", "args": {...}}, ...], repeated repeat times (default 1). Each step answers with its first line and its warnings (show="full": everything; "last": everything of the last step only). Stops at the first error unless stop_on_error=false. At most 500 calls. For repeated or routine work (the same edit on many parts, edit-check loops); a step's answer cannot feed the next one's arguments.

Arguments:

- `repeat` (integer, >= 1)
- `show` (one of line, last, full)
- `steps` (array, required)
- `stop_on_error` (boolean)

## tool_help

A tool's full description: examples, defaults, formulas, limits. Use when a short description is not enough.

Arguments:

- `name` (string, required): a tool's name
